# Harmonicst - Music Artist Website

A modern, responsive React website for music artist Harmonicst, built with Vite.

## Features

- **Hero Section**: Eye-catching landing page with call-to-action buttons
- **About Section**: Artist biography and story
- **Music/Discography**: Showcase of albums and releases
- **Contact Form**: Interactive form for fan engagement

## Tech Stack

- React 18
- Vite (Fast build tool)
- Modern CSS with responsive design
- Component-based architecture

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Visit `http://localhost:5173` to view the site.

### Build

Create a production build:

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
